# 🏨 Bookin – Панель управления бронированием отелей

**Bookin** — это мощная и интуитивно понятная панель администратора, созданная с использованием **Streamlit** и **MongoDB**, которая позволяет администраторам отелей удобно управлять бронированиями.

![BookinДемо](https://github.com/KrishBharadwaj5678/Bookin/raw/main/BookinDemo.png)

## ✨ Возможности

| Функция                               | Описание                                                            |
| ------------------------------------- | ------------------------------------------------------------------- |
| ✅ **Добавление новых бронирований**   | Легко добавляйте информацию о гостях и предпочтениях номеров        |
| 📝 **Редактирование бронирований**    | Быстро и удобно изменяйте данные бронирования                       |
| 👀 **Просмотр всех бронирований**     | Отображение всех бронирований в организованном и удобном интерфейсе |
| ❌ **Удаление бронирований**           | Удаление бронирований, которые больше не нужны                      |
| 📊 **База данных в реальном времени** | Подключение к MongoDB для мгновенного обновления данных             |
| 🚀 **Интерфейс на Streamlit**         | Лёгкий, интерактивный и адаптивный веб-интерфейс                    |

---

## 🛠️ Технологии

| Инструмент       | Назначение                                                 |
| ---------------- | ---------------------------------------------------------- |
| 🚀 **Streamlit** | Фронтенд-фреймворк для создания интерфейса                 |
| 🍃 **МонгоБД**   | NoSQL база данных для хранения и управления бронированиями |
| 🐍 **Питон**    | Серверная логика и управление приложением                  |
| 🔗 **PyМонго**   | Подключение Python к MongoDB для работы с данными          |

## 🚀 Начало работы

### 1️⃣ Клонируйте репозиторий

```bash id="9dgq1q"
git clone https://github.com/KrishBharadwaj5678/Bookin.git
```

### 2️⃣ Перейдите в папку проекта

```bash id="91a0wn"
cd Bookin
```

### 3️⃣ Установите зависимости

```bash id="e0n8hi"
pip install -r requirements.txt
```

### 4️⃣ Создайте файл `.env`

Создайте файл `.env` в корневой директории проекта и добавьте строку подключения MongoDB:

```env id="0u6k4k"
MONGO_URI=your_mongodb_connection_string
```

### 5️⃣ Запустите приложение

```bash id="9gr3g9"
streamlit run app.py
```
